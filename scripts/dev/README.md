# Scripts de desarrollo / tuning

Scripts opcionales para tuning y experimentación. No requieren para el uso normal del sistema.

- **optimize_to_20pct.py**: Prueba combinaciones de config hasta alcanzar ≥20% anual (LONG)
- **run_backtest_quick.py**: Backtest rápido sobre cache existente
- **tune_short.py**: Grid de parámetros para estrategia SHORT
